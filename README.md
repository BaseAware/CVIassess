# Baseline VCI Preparedness Assessment

Web app version of the Baseline Awareness *Violent Critical Incident Preparedness Assessment*.

- 11 scored areas with the full rubric (0–10) and security value multipliers (max 135 points)
- Live weighted scoring sheet, percentage score, and largest point gaps
- Per-area observation notes
- Multiple saved assessments (stored in the browser), duplicate, delete
- Copy summary, export/import JSON, print-ready report
- Brand intro video on first load (`assets/intro.mp4`)

No build step. Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, S3).

Note: School Climate levels 5, 7 and 10 and the Situational Awareness and Family Reunification explanations were drafted from U.S. Secret Service NTAC, CISA/USSS Bystander Reporting Toolkit, U.S. Dept. of Education school climate, and I Love U Guys Standard Reunification Method guidance. Review before field use.
